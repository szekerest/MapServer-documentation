The ``measure`` attribute controls how scalebar distances are calculated. It
uses ``MS_SCALEBAR_MEASURE_CARTESIAN`` by default, or
``MS_SCALEBAR_MEASURE_GEODESIC`` for local ellipsoidal ground-distance
measurement.
